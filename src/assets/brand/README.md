# Sidebar wordmark

`clawx-wordmark.png` is the approved compact ClawX wordmark (design option 2,
2026-10-24). It includes the small curved terminal on the upper-right arm of X.
It was produced from the selected design with Image Gen, then trimmed and
downsampled to a 512px-wide transparent asset for desktop display.

Render its alpha channel as a mask with the theme foreground colour. Keep the
wordmark's aspect ratio, optical spacing, and original letter shapes. Do not
replace it with system text, a different font, or hand-drawn letter paths.

The blue lobster symbol is supplied separately by `../logo.svg` and remains
unchanged. The wordmark asset contains no blue symbol or background.
